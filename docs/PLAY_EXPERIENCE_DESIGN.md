# 棋聚 QIJU：遊玩介面與 3D 體驗設計

本文件細化 [P3 使用體驗與可及性](P3_PRODUCTIZATION_PLAN.md#p3-3使用體驗與可及性) 的遊玩介面方向。目標是讓每款遊戲都有值得進入的桌面、清楚的操作與適度的臨場感；玩家從選遊戲到結算，始終知道自己可以做什麼、發生了什麼，以及接下來輪到誰。

## 參考與取捨

任天堂[《Clubhouse Games: 51 Worldwide Classics》官方介紹](https://www.nintendo.com/us/store/products/clubhouse-games-51-worldwide-classics-switch/)展示了桌面遊戲的材質與物理回饋，也提供教學、輔助操作和部分遊戲的撤回功能。[官方多人遊玩說明](https://en-americas-support.nintendo.com/app/answers/detail/a_id/49683/p/989)則呈現了先選人數與操作方式，再挑選相容遊戲的流程，以及進入多人模式前建立小人偶的引導。棋聚借用「容易開始、每款遊戲有個性、互動有回饋」的設計原則，另行創作自己的場景、美術與角色。

## 遊玩體驗的共同骨架

| 階段     | 玩家首先需要看到                       | 介面與互動                                                                                 |
| -------- | -------------------------------------- | ------------------------------------------------------------------------------------------ |
| 選遊戲   | 人數、局長、難度、支援模式             | 卡片預覽桌面風格；篩選結果只顯示當前人數與模式可玩的遊戲；可直接查看規則摘要               |
| 開局設定 | 對手、座位、規則、是否計分             | 在同一頁確認設定並預覽桌面；顯示新手教學入口，不讓過場取代必要資訊                         |
| 對局中   | 棋盤／牌桌、輪到誰、可行操作、最近一步 | 操作區最大且穩定；狀態、計時、歷史與聊天依重要性排列；選取、確認、拒絕都有即時且不同的回饋 |
| 對局結束 | 勝負、原因、關鍵紀錄與下一步           | 短結算動效後保留可閱讀的結果、重賽、返回大廳及適用時的重播入口                             |

手機版先保留完整操作區，再將歷史、聊天與說明收進可切換面板。桌機版讓棋盤與狀態並排。任何裝置上，彈窗、動效、聊天與角色都不能遮住當前必須操作的格位、手牌或計時警告。

## 視覺語言與每款遊戲的個性

共用「棋聚桌面」的形狀、間距、字級、狀態色與按鈕行為；每款遊戲透過桌面材質、棋盤邊框、棋子、音效及環境細節建立辨識度。開局卡片、設定頁、對局桌與結算頁使用同一組遊戲主題，讓場景轉換連續。首批主題以將棋、西洋棋、圍棋、日麻作為四種材質與操作形態的代表，其他遊戲再沿用共用元件擴充。

主題 token 至少分開定義頁面、面板、文字、棋盤格、棋子、可走位置、選取、上一手、焦點、警告與勝負狀態。除了色彩，合法走法、將軍／警告和目前回合也使用形狀、標記或文字。先完成 light／dark 的 2D 主題，再讓 3D 場景引用相同語意 token；主題與鏡頭不改變棋規、命中區、棋子名稱或資訊可見範圍。

## 3D 如何進入實際對局

1. **桌面層次：** 先在現有 2D 棋盤加入桌面底板、棋盤厚度、柔和陰影、棋子受光與有節制的擺放回饋。這是預設呈現，也是所有裝置的完整回退版本。
2. **可選 3D 對局桌：** 以一款代表遊戲做固定或有限角度的 3D 原型。盤面維持正視或近正視、座標與棋子容易辨讀；點擊／觸控先映射到穩定的棋盤座標，再送到既有遊戲狀態與權威規則。不得用鏡頭透視改變可點擊格位或暗牌可見性。
3. **場景互動：** 已確認的落子可帶動棋子抬起、移動、放下與桌面聲響；選取時提供短暫高亮或投影；輪到自己時用桌面邊緣或座位提示。玩家可隨時操作，動畫可中斷或快速完成，不必等鏡頭表演。
4. **環境氛圍：** 可選的房間佈景、燈光與桌邊細節放在操作區之外；開局與結算可有較完整的鏡頭轉場，對局中不主動旋轉、震動或遮擋棋盤。

日麻另設固定玩家視角，手牌、牌河、鳴牌與分數保持清楚分區；3D 牌桌不得展示其他玩家暗牌。線上對局只播放權威狀態確認後的操作效果；本機模式只播放規則引擎確認後的效果。重連或補同步時以最新狀態直接重建場景，避免重播過期動畫。

## 人物與陪伴感

先加入可選的玩家頭像或桌邊小人偶，顯示座位、暱稱、輪到誰與表情回饋。新手引導角色只在開局教學、操作提示或結算說明出現；提示可跳過、可關閉，不替玩家作決定。AI 對手可有有限的待機與落子反應，但不以動畫暗示尚未確定的思考結果。多人互動只使用預設表情與明確的封鎖／靜音設定，不讓角色覆蓋聊天與對局資訊。

人物、美術、台詞與動畫都採棋聚原創；角色是提高辨識與陪伴感的可選層，關閉後遊玩、教學與結果資訊仍完整。

## 技術邊界與裝置策略

- 現有 `src/client/app.ts` 與 `src/client/riichi-ui.ts` 保持遊戲狀態到畫面的轉換入口；渲染器只接收可顯示的盤面快照與已確認事件，不加入棋規判斷。互動回傳座標或 action，仍由既有流程驗證。
- 對局 HUD、按鈕、文字、計時與可及性語意保留 DOM；3D 只處理桌面、棋子、角色與環境。畫面閱讀器使用同一份狀態描述，不依賴讀取 canvas 內容。
- 3D 模型、材質與音訊依棋種載入，預設不阻擋開局；載入失敗、WebGL 不可用或裝置負載偏高時立即使用 2D。玩家可在設定中固定選擇 2D、3D 或自動，不於對局中強制切換。
- 降低動態設定同時遵循 `prefers-reduced-motion` 與玩家選項；停用鏡頭移動、縮短棋子動作。背景分頁暫停裝飾更新；音效有總開關與音量控制。
- 先建立一份小型代表場景比較 2D 與 3D 的啟動時間、操作延遲、穩定度、手機耗電與可讀性，再決定是否擴到其他棋種。資源大小與畫面效能門檻應在原型量測後寫入驗收，不以未測得的數字承諾。

## 分階段交付

| 階段          | 可交付結果                                                                        | 驗收重點                                                                               |
| ------------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| A：介面骨架   | 重整桌機／手機對局資訊層級；統一開局、對局、結算；補上主題 token 與清楚的操作狀態 | 八款遊戲（含日麻）的主要流程可完成；小螢幕仍看得清棋盤與必要操作；鍵盤焦點在重繪後保留 |
| B：桌面手感   | 各遊戲的 2D／2.5D 桌面主題、已確認事件的短動畫與音效                              | 動效可關閉；輪到誰、合法走法、錯誤、計時及終局不只靠聲音或顏色表達                     |
| C：3D 原型    | 一款棋種提供可選 3D 對局桌、有限鏡頭、棋子互動與 2D 回退                          | 2D／3D 操作產生相同座標與結果；手機、觸控、重連及低負載模式可用                        |
| D：角色與擴充 | 自創座位人物、新手引導和各棋種場景；依原型結果擴充 3D                             | 角色可關閉；不遮盤面、不洩漏暗牌；新場景沿用既有狀態與可及性契約                       |

階段 A、B 是整體遊玩介面優化的基礎；階段 C、D 依實測效果擴充。3D 對局桌要帶來辨識度與手感，不能讓讀盤、落子或載入變慢到影響完成一局棋。

## 實作現況（2026-09-26）

- 已有可切換的 2.5D 棋盤外觀、棋種桌面色調，以及一般棋類棋盤的方向鍵操作與重繪後焦點保留。
- 西洋棋已有可選的 3D 對局桌原型。棋子、棋盤與桌面由本地 bundle 產生；滑鼠、觸控與鍵盤操作回到同一份 2D 棋盤事件與權威棋規，且可即時切回 2D。WebGL 不可用時會保留可玩的 2D 棋盤。
- 西洋棋、圍棋、黑白棋已加入可關閉的原創桌邊角色。音效、新手引導與其餘棋種場景尚未實作；低階手機實機的載入時間、耗電與操作可讀性仍待量測。

## 3D 操作補強

- 西洋棋 3D 棋盤的鍵盤游標有可見邊框與座標；切回 2D 後保留目前游標位置。
- 已確認的走子沿原格到目標格播放短動畫；降低動態設定直接顯示最終位置，動畫中仍可繼續操作。
- 手機的棋類對局持續顯示回合與操作按鈕；紀錄與線上聊天可按需展開，避免資訊區把棋盤推得過遠。日麻仍使用專屬牌桌版面。
- 西洋棋會記住玩家上次選的 2D／3D；本機續局與線上房間重連恢復顯示模式。WebGL 失效時改記為 2D，重連快照直接同步，不補播過期動畫。
- 圍棋新增可選 3D 木盤與黑白棋子，支援 9／13／19 路、交叉點觸控與鍵盤落子、提子後畫面同步及數子階段死棋標記。19 路手機觸控先預覽位置，再點一次確認落子。西洋棋與圍棋各自記住顯示選擇，並共用按需載入的 3D 核心模組。

### 桌邊角色（已實作）

西洋棋、圍棋與黑白棋 3D 共用原創木製小人偶，置於棋盤外；目前回合的底座會亮起。可透過「桌邊角色」開關隱藏，設定會保存並套用到三款遊戲。角色不持續播放動畫，離開對局時釋放資源。

### 黑白棋與穩定性（已實作）

- 黑白棋新增可選 3D 木框綠色棋盤、雙面棋子、合法落點提示、游標與最後落子標記。權威盤面中的換色棋子播放 360ms 翻面動畫；降低動態設定直接顯示結果。
- 支援鍵盤、手機觸控、悔棋、保存顯示選擇及線上房間重連。重連快照不補播翻面，WebGL 中斷可切回可操作的 2D 棋盤。
- 三款 3D 都限制畫布最大邊長 1200px、DPR 上限 2，沒有持續待機動畫；隱藏棋盤不因角色開關額外渲染，重複離開不重複釋放資源。
- 自動化驗證採 390×844、DPR 3 模擬手機，檢查解析度上限、靜止時不排程動畫影格、降低動態時落子不排程動畫，以及 WebGL 中斷後可用的 2D 回退。這些檢查不代表低階手機實機的耗電或幀率結果。
